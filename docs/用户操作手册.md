## 一、这是什么

一句话：**给它一个视频和一份日程表，它还你一整套课程资产。**

| 你给的（输入） | 它做的（解牛七式） | 你拿到的（输出） |
|---|---|---|
| 直播/回放链接，或本地视频文件 | 下载 → 转写 → 标点 → 对齐 → 切片 → 成文 → 出课件 | ① 每位讲者的切片视频（含字幕）② 同步字幕文件 ③ 逐字稿 Word（附总结）④ 脑图 ⑤ 还原 PPT |
| （可选）会议日程表：图片 / PDF / 文字 | | |

特点：**全程本地离线运行，零费用、零隐私风险**；无人值守，一句话指令即可。

## 二、安装（二选一）

### 方式 A：口令一键安装（推荐）

打开你的 AI 助手（Kimi / Codex / Claude / Workbuddy 任意一个），原样发送这句话：

> **帮我安装这个技能并立即生效：https://github.com/zhuangyd19-cyber/lecture-replay-slicer**

助手会自动完成：从 GitHub 拉取 → 放入本机技能目录 → 验证可用。全程约 1–2 分钟。

### 方式 B：手动安装

1. 下载仓库：在 GitHub 页面点 `Code → Download ZIP`，或 `git clone https://github.com/zhuangyd19-cyber/lecture-replay-slicer.git`
2. 解压后把整个文件夹放进对应平台的技能目录：

| 平台 | 技能目录 |
|---|---|
| Kimi Work | `~/Library/Application Support/kimi-desktop/daimon-share/daimon/skills/` |
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |
| WorkBuddy | `~/.workbuddy/skills/` |

3. 重启或刷新助手，说「庄生解牛」验证——助手回应即安装成功。

### 运行环境（首次使用前检查）

- **ffmpeg**：必装。Mac：`brew install ffmpeg`；Windows：官网下载并加入 PATH
- **Python 3.10+**
- **语音识别后端**（二选一，首次运行时会引导）：
  - Apple 芯片 Mac：`pip install mlx-whisper`
  - 其它电脑：`pip install faster-whisper`
- 国内用户建议设置模型下载加速：`HF_ENDPOINT=https://hf-mirror.com`

> 不用背：技能内置 `scripts/detect_env.py`，会自动探测你的电脑配置并告诉你该装哪个、选哪个模型。

## 三、快速上手（三分钟跑通）

**第 1 步**：对助手说出需求，例如：

> 「这是年会回放的 5 个链接和一张日程表，帮我下载下来，按每位老师切成片段，配上字幕，再生成逐字稿和 PPT。」

**第 2 步**：去喝杯水。10 小时的回放约需 1–3 小时（视电脑配置），全程无需看守。

**第 3 步**：在输出目录验收成果：

```
输出文件夹/
├── cut/        切片视频（内嵌字幕轨 + 同名外挂 srt，IINA/VLC 自动加载）
├── docs/       逐字稿 Word（每位讲者一份，含 3–5 句内容总结）
├── docs/mindmap/  每场报告的脑图（Mermaid 格式）
└── ppt/        从视频画面还原的可编辑 PPT
```

**暗号**：对助手说一声「**庄生解牛**」，也能直接唤醒本技能。

## 四、典型场景与说法

| 场景 | 你这样说 |
|---|---|
| 只有回放链接 | 「把这个链接的视频下载下来：https://…」 |
| 本地已有视频 | 「处理这个文件 /Users/…/年会.mp4，按日程切片」 |
| 按讲者切 | 「按每位老师切成独立片段，配上字幕」 |
| 只要文字 | 「生成逐字稿和每段的内容总结」 |
| 做课件 | 「把讲课内容还原成 PPT」 |
| 字幕有问题 | 「字幕和声音对不上，帮我校验修复」 |
| 没有日程表 | 「听内容自动分段」或「每 10 分钟切一段」 |

日程表可以拍照、截图、PDF、文字粘贴，都能识别。

## 五、常见问题（FAQ）

**Q1：收费吗？**
完全免费，MIT 开源。语音识别在本地跑，不消耗任何 token 或云端额度。

**Q2：视频会上传到云端吗？**
不会。下载、转写、切片全部在你自己电脑上完成，一字一帧不出本机。

**Q3：支持哪些视频来源？**
小鹅通等 H5 回放、B站、YouTube，以及任何本地视频文件（mp4/mov/mkv 等）。

**Q4：字幕准不准？**
实测字幕与声音偏差 ≤ ±15 秒以内；技能内置 `align_check.py` 自动抽样复听校验，发现漂移会定点重识别修复。

**Q5：电脑要什么配置？**
普通办公电脑即可。Mac M 系列芯片会自动选用加速后端；内存越大可选越大的模型（更准确）。技能会按你的机型自动选型。

**Q6：处理中途能停吗？**
可以。中断后把同样的话再说一遍，已完成的步骤会自动跳过/续跑。

**Q7：会不会侵犯版权？**
请只处理**你本人已获授权观看**的内容（自己报名的课程、公开直播、自有素材），用于个人学习存档；不要用于破解付费内容或二次传播。

**Q8：报错或卡住怎么办？**
先对助手说「继续」；仍有问题，把报错信息发到 GitHub Issues：
https://github.com/zhuangyd19-cyber/lecture-replay-slicer/issues

## 六、进阶：单独使用某个脚本

五个脚本都可独立运行（在仓库 `scripts/` 目录）：

| 脚本 | 用途 | 示例 |
|---|---|---|
| `download_video.py` | 下载视频 | `python3 download_video.py <链接>` |
| `transcribe_srt.py` | 转写字幕 / 定点修复 | `python3 transcribe_srt.py video.mp4` |
| `align_check.py` | 音字对齐校验 | `python3 align_check.py video.mp4 sub.srt` |
| `slice_video.py` | 无损切片 | `python3 slice_video.py video.mp4 边界表.csv` |
| `make_seg_docs.py` | 生成逐字稿等文档 | `python3 make_seg_docs.py 切片目录/` |

更详细的配置见仓库 `references/` 目录（ASR 配置、各平台下载方法、日程解析、交付物生成、踩坑清单）。
