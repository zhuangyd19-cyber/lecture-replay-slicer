# 日程表 → 切片边界表

用户给的日程通常是图片或 PDF（会议手册页）。目标产物是 `slice_video.py` 用的 CSV：`name,start,end`（秒）。

## 关键：日程是墙钟，视频是偏移

录像的时间轴从"开始录制"起算，和日程上的"14:00–14:30"通常不一致。对齐方法：

1. 读日程（PDF 直接读文本；图片用视觉识别），得到每位讲者的墙钟时段和顺序。
2. 定锚点：在视频里找到第一个讲者开场的偏移——用转写结果搜索其姓名/题目/开场白（如"下面有请""我是来自"），或在预计位置附近用 ASR 探测确认。
3. 一个锚点 + 日程时长推出全部边界；相邻讲者之间的串场/掌声归到后一段开头或单独成段。
4. **逐段验证**：每段起点的音频 ASR 应与该讲者身份吻合；误差控制在 ±5 秒内。用户发现的"内容与标题不匹配"几乎都是边界没验证。

## 边界表规范

- 每场报告/环节一行，`name` 建议 `序号-讲者-题目`（会作为文件名，勿含 `/:*?"` 等字符）。
- 开幕式、圆桌、颁奖、闭幕式也各成一段，方便用户按主题取用。
- 场间休息/纯音乐段不切片。

## 示例

```csv
name,start,end
01-开幕式,1790,2540
02-苏永康-人工智能教育应用,2660,4520
03-祝智庭-AI时代的教育变革,4613,6740
```
